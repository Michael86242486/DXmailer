### 3. ASYNCHRONOUS GMAIL ROTATION LOOP (CRITICAL)
Build a Cloudflare Queue consumer service to process queued messages. The loop must execute as follows:
- **Atomic Selection Query:** Run a D1 query to fetch the absolute most optimal active Gmail node: `SELECT * FROM smtp_pool WHERE status = 'active' AND daily_sent_count < max_daily_limit ORDER BY last_used_timestamp ASC LIMIT 1`. If no nodes are available, throw a hard capacity error.
- **Template Engine:** Include built-in HTML layouts (verification, otp, password-reset, magic-link, security-alert, welcome-email). Compile the layout using string interpolation or basic mustache/handlebars syntax to replace `{{variable}}` keys with values provided in the `data` object.
- **Outbound TCP Delivery:** Establish a secure connection to `://gmail.com` (STARTTLS) using the `worker-mailer` library and the selected credentials. Mask the headers cleanly: `From: "${senderName} via ORACLEX" <pooled_gmail@gmail.com>`.
- **State & Error Handling:**
  - On Success: Increment `daily_sent_count` by 1, update `last_used_timestamp` to `Date.now()`, and mark log status as 'sent'.
